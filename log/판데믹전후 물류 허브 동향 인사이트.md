## 📋 Executive Summary

본 분석은 FAF5(Freight Analysis Framework) 데이터를 활용하여 미국 국내 지상 물류(Truck, Rail, Multiple modes)의 최적 허브 배치를 도출하였습니다. MCLP(Maximal Covering Location Problem) 최적화 기법을 적용하여 팬데믹 전후 물류 네트워크 변화를 비교 분석하였습니다.

**핵심 결과:**
- 최종 권장: **1000 miles 서비스 반경, 6개 primary 허브**
- 커버리지: **100%** (51개 주 전체)
- 팬데믹 후 **동부 중심 재편** (50% 허브 교체)

## 🎯 분석 목적 및 방법론

### 목적
1. 미국 국내 물류 최적 허브 위치 선정
2. 팬데믹 전후 물류 네트워크 변화 분석
3. 실무적 허브 전략 수립

### 방법론

**데이터:**
- FAF5 (Freight Analysis Framework Version 5)
- 분석 기간: PRE (2018-2019) vs POST (2022-2024)
- 필터링: Domestic(trade_type=1), Ground transport(mode=1,2,5)
- 데이터 규모: 495,247 rows, 2,436 OD pairs

**최적화 모델:**
- **MCLP (Maximal Covering Location Problem)**
- 목적: 가중치 기반 커버리지 최대화
- 가중치: post_power(80%) + resilience_score(20%)
- 제약: 서비스 반경(threshold), 허브 개수(p)

**주요 변수:**
- `power` = out_tons + in_tons (물동량)
- `resilience_score` = growth_rate(70%) + value_per_ton(30%)
- `threshold` = 서비스 반경 (miles)
- `p` = 허브 개수
