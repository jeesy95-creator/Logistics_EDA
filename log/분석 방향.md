## 📊 Analysis Plan

본 프로젝트는 FAF5 물류 데이터를 활용하여  
미국 국가 물류 구조와 정책적 시사점을 도출하는 것을 목표로 한다.

---

### 1. State(주)별 물류 허브 파워 분석

사용 변수  
- dms_orig, dms_dest  
- tons_YYYY, value_YYYY  

파생 변수  
- Outbound Tons (출발 물동량)  
- Inbound Tons (도착 물동량)  
- Hub Index = Outbound + Inbound  
- Value per Ton = value / tons  

분석 질문  
- 가장 많은 화물을 보내는 주는 어디인가?  
- 가장 많은 화물을 받는 주는 어디인가?  
- 물량 대비 가치가 높은 주는 어디인가?  

---

### 2. 운송 모드(dms_mode)별 역할 비교

사용 변수  
- dms_mode  
- tons_YYYY, value_YYYY  

파생 변수  
- Mode Share (모드별 물량 비중)  
- Value Density = value / tons  

분석 질문  
- 물량 기준 지배적인 모드는 무엇인가?  
- 가치 기준 지배적인 모드는 무엇인가?  
- 항공(Air)은 고부가가치 화물 중심인가?  

---

### 3. 품목(SCTG2)별 산업 특성 분석

사용 변수  
- sctg2  
- tons_YYYY, value_YYYY  

파생 변수  
- Commodity Value Density = value / tons  

분석 질문  
- 저중량·고가 품목은 무엇인가?  
- 고중량·저가 품목은 무엇인가?  

---

### 4. 거리 구간(dist_band)에 따른 모드 선택 패턴

사용 변수  
- dist_band  
- dms_mode  
- tons_YYYY  

파생 변수  
- Long Distance Flag (dist_band ≥ 6)  

분석 질문  
- 장거리 운송에서 트럭 의존도가 여전히 높은가?  
- 철도는 장거리 운송에서 대안 역할을 하는가?  

---

### 5. Domestic vs International 물류 구조 비교

사용 변수  
- trade_type  
- tons_YYYY, value_YYYY  

파생 변수  
- International Flag (trade_type ∈ {2,3})  

분석 질문  
- 국제 물류는 국내 물류보다 가치 비중이 높은가?  
- 국제 물류에서 항공 비중이 높은가?  

---

### 6. 주별 물류 포트폴리오 다양성

사용 변수  
- dms_orig  
- sctg2  

파생 변수  
- Number of Commodities (주별 품목 개수)  

분석 질문  
- 특정 산업에 의존하는 주는 어디인가?  
- 산업적으로 다양한 종합 허브 주는 어디인가?  

---

### 7. 물류 효율성 지표 개발

사용 변수  
- tons_YYYY, value_YYYY, tmiles_YYYY  

파생 변수  
- Value per Ton  
- Ton-miles per Ton  
- Value per Ton-mile  

분석 질문  
- 어느 주가 가장 효율적인 물류 구조를 가지는가?  

---

### 8. 2018–2024 물류 성장 추세

사용 변수  
- tons_YYYY  
- value_YYYY  

파생 변수  
- CAGR (연평균 성장률)  

분석 질문  
- 물동량은 증가하고 있는가?  
- 가치 성장은 물동량 성장보다 빠른가?  

---

### 9. 주(State) 단위 물류 스타일 클러스터링

입력 변수  
- Truck Share  
- Rail Share  
- Air Share  
- Avg Value per Ton  

클러스터 예시  
- Truck-heavy 대량형  
- Rail 중심 장거리형  
- Air 중심 고부가형  

---

### 10. 정책 시뮬레이션

시나리오 예시  
- 트럭 물동량의 10%를 철도로 전환  

평가 지표  
- tmiles 변화량  
- Value per Ton-mile 변화  

목표  
- 친환경 및 인프라 투자 효과 정량화
