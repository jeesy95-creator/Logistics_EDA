# 📌 FAF Logistics Dataset – Variables

본 문서는 FAF5.7.1 물류 데이터 분석에 사용되는  
주요 원본 변수와 파생 변수 목록과 상세 설명을 정리한 것이다.

---

## 기본 식별 변수

- dms_orig : 미국 국내 FAF 출발 존 코드  
  → 화물이 출발한 미국 내 지역 식별자

- dms_dest : 미국 국내 FAF 도착 존 코드  
  → 화물이 도착한 미국 내 지역 식별자

- fr_orig : 해외 출발 존 코드  
  → 해외에서 출발한 국제 물류 흐름 식별자

- fr_dest : 해외 도착 존 코드  
  → 해외로 도착하는 국제 물류 흐름 식별자  

---

## 품목(Commodity) 변수

- sctg2 : SCTG 2자리 품목 코드  
  → 화물의 산업·상품 유형 분류 코드

- sctg2_name : SCTG 품목명 (메타데이터 매핑)  
  → 코드에 대응되는 품목의 실제 명칭

---

## 운송 모드 변수

- dms_mode : 국내 구간 운송 모드  
  → 미국 내부 구간에서 사용된 운송 방식

- fr_inmode : 수입(Import) 해외→미국 입경 모드  
  → 해외에서 미국으로 들어올 때 사용된 모드

- fr_outmode : 수출(Export) 미국→해외 출경 모드  
  → 미국에서 해외로 나갈 때 사용된 모드  

---

## 거래 유형 변수

- trade_type  
  → 물류 거래의 성격 구분 코드  

  - 1 = Domestic (미국 내부 이동)  
  - 2 = Import (해외 → 미국)  
  - 3 = Export (미국 → 해외)  

---

## 거리 변수

- dist_band : 평균 가중거리 구간 (1~8)  
  → 화물이 이동한 평균 거리 범주

---

## 연도별 측정 변수

- tons_YYYY : 물동량 (천 톤)  
  → 해당 연도에 이동한 화물 중량

- value_YYYY : 가치 (백만 달러, 2017 불변)  
  → 물가 변동을 제거한 실질 가치

- current_value_YYYY : 가치 (백만 달러, 명목)  
  → 해당 연도 기준 실제 거래 가치

- tmiles_YYYY : 톤마일 (백만)  
  → 화물 중량 × 이동 거리

# 파생 변수 (Derived Variables)

---

## 시간 관련

- year : 연도 (YYYY)  
  → 컬럼명에서 추출한 연도

---

## 물류 규모

- outbound_tons : 출발 기준 총 물동량  
  → 주/존이 외부로 보낸 화물량
```
outbound_tons = base.groupby("dms_orig")["tons"].sum()
```

- inbound_tons : 도착 기준 총 물동량  
  → 주/존이 외부에서 받은 화물량
```
inbound_tons = base.groupby("dms_dest")["tons"].sum()
```

- hub_index = outbound_tons + inbound_tons  
  → 해당 지역의 물류 허브 영향력 지표
```
hub = pd.concat([outbound_tons, inbound_tons], axis=1)
hub.columns = ["outbound_tons", "inbound_tons"]
hub["hub_index"] = hub.sum(axis=1)
```

---

## 가치 밀도

- value_per_ton = value / tons  
  → 화물 1톤당 평균 가치
```
base["value_per_ton"] = base["value"] / base["tons"]
```

- value_per_tmile = value / tmiles  
  → 이동 거리 1마일당 창출 가치
```
base["value_per_tmile"] = base["value"] / base["tmiles"]
```

---

## 거리 효율

- tmiles_per_ton = tmiles / tons  
  → 화물 1톤이 평균적으로 이동한 거리
```
base["tmiles_per_ton"] = base["tmiles"] / base["tons"]
```

---

## 거래 유형 플래그

- international_flag : trade_type ∈ {2,3}  
  → 국제 물류 여부
```
base["international_flag"] = base["trade_type"].isin([2, 3])
```

- domestic_flag : trade_type == 1  
  → 국내 물류 여부
```
base["domestic_flag"] = base["trade_type"] == 1
```

---

## 거리 구간 플래그

- long_distance_flag : dist_band ≥ 6  
  → 장거리 운송 여부
```
base["long_distance_flag"] = base["dist_band"] >= 6
```

- short_distance_flag : dist_band ≤ 3  
  → 단거리 운송 여부
```
base["short_distance_flag"] = base["dist_band"] <= 3
```

## 모드 점유율

- truck_share  
  → 트럭 운송 물동량 / 총 물동량

- rail_share  
  → 철도 운송 물동량 / 총 물동량

- water_share  
  → 수운 운송 물동량 / 총 물동량

- air_share  
  → 항공 운송 물동량 / 총 물동량

```
#출발지(dms_orig) × 모드(dms_mode)별 tons 합계 → wide 형태로 변환
mode_share = (
    base.groupby(["dms_orig", "dms_mode"])["tons"]
        .sum()
        .unstack(fill_value=0)
)

#모드 코드를 share 컬럼명으로 매핑
MODE_MAP = {
    1: "truck_share",
    2: "rail_share",
    3: "water_share",
    4: "air_share",
}
mode_share = mode_share.rename(columns=MODE_MAP)

#원하는 4개 모드 컬럼만 고정(없는 모드는 0으로 생성)
wanted = ["truck_share", "rail_share", "water_share", "air_share"]
for c in wanted:
    if c not in mode_share.columns:
        mode_share[c] = 0.0
mode_share = mode_share[wanted]

#행(출발지)별 총 tons로 나눠서 비율로 변환
den = mode_share.sum(axis=1).replace(0, np.nan)     # 분모 0 방지
mode_share = mode_share.div(den, axis=0).fillna(0)  # 비율(0~1)

#검증: 출발지별 합이 1인지 체크(부동소수 오차 감안)
mode_share["share_sum_check"] = mode_share[wanted].sum(axis=1)

mode_share.head()
```

## 성장 지표

- yoy_growth_tons  
  → 전년 대비 물동량 성장률
```
yoy_growth_tons = base.groupby("year")["tons"].sum().pct_change()
```

- yoy_growth_value  
  → 전년 대비 가치 성장률
```
yoy_growth_value = base.groupby("year")["value"].sum().pct_change()
```

- CAGR_tons  
  → 물동량 연평균 성장률
- CAGR_value  
  → 가치 연평균 성장률
```
yearly = base.groupby("year")[["tons", "value"]].sum()

cagr_tons  = (yearly["tons"].iloc[-1] / yearly["tons"].iloc[0]) ** (1/6) - 1
cagr_value = (yearly["value"].iloc[-1] / yearly["value"].iloc[0]) ** (1/6) - 1
```
